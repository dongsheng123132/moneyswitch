## 🎯 四大主赛道详细说明

### 赛道 01：Onchain Finance & Trading
**新资产原语、市场结构和交易体验，都由快速廉价结算成为可能。**

$30,000 · 3 个获奖团队

**适合做：**
- 完全链上的订单簿（不需要链下撮合引擎）
- 每块更新资金费率的永续合约

**最佳团队画像：** 之前做过交易、借贷或做市产品的团队

## 🎯 MoneySwitch 项目现状

### 已选赛道和赏金
| 类型 | 选择 |
|---|---|
| 主赛道 | Trust, Identity & AI Infrastructure ✅ |
| 赏金 1 | Mera: One Passkey, Many Keys ($2,500) ✅ |
| 赏金 2 | Best use of Nansen ($5,000) ✅ |
| 赏金 3 | Best Builds with Qwen 3.8 Max ($5,000 额度) ✅ |

### 项目核心
- **MoneySwitch** = 给 AI agent 发个 API Key 就能安全花 USDC
- 用 x402 协议，跑在 Monad testnet 上
- Agent 永远拿不到私钥，只有 `mk_live_` MoneyKey
- 双向：能花钱（买家）+ 能收钱（收费站 toll booth）
- 已有 12 笔真实链上交易

## 💡 冲奖策略建议

### 优先级 1：把 Mera 两个赏金打满（$5,000）
- 你已经选了 "One Passkey, Many Keys"
- **建议再加 "Best Mera-Powered UX"**（$2,500）—— 把钱包层换成 Mera passkey
- 理由：都是 Monad 官方自己的赏金，内部人评，最容易拿

### 优先级 2：MetaMask Agent Wallet 插件（$2,500）
- 做一个 MetaMask 插件，让 agent 用 MoneyKey 而不是私钥
- 工作量不大，但评委喜欢这种"真实用例"

### 优先级 3：Nansen 赏金怎么拿稳
- 不要只"展示 Nansen 数据"——要做**超越原始数据的产品体验**
- 建议：加一个"收款方风险评级"面板
  - 用 Nansen API 查收款地址是否有黑钱关联
  - 风险高的地址自动拦截付款
  - 这才叫"powered by Nansen"，而不是"用 Nansen 数据"

### 优先级 4：通义千问赏金
- 在 Dashboard Playground 里集成 Qwen 作为默认演示 agent
- 一句话："试试用 Qwen 驱动的 agent 自己买东西"

### 提交时要突出
1. **真实链上数据**：12 笔 Monad testnet 真实结算，tx hash 列出来
2. **x402 原生**：用官方 SDK，不造轮子
3. **安全叙事**："Agent 永远拿不到私钥" + "策略在签名前执行"
4. **双向价值**：买家 + 卖家（收费站）都能做
5. **即插即用**：`npx moneyswitch demo` 一行命令跑起来
