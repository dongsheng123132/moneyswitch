## 适合提交什么

Show HN 的对象应是可以运行和体验的 MoneySwitch 项目。以能够找到源码、运行说明和试用步骤的产品入口为主，不把纯招募页当成 Show HN。若只分享一篇博客，可以考虑普通链接投稿，标题与讨论仍由本人写。

产品当前自部署，首次体验要准备运行环境、测试 USDC 和支持 HTTP 的 Agent。这些是真实的门槛。投稿前亲自走一遍新用户路径，确认无需向你索要管理员令牌；不要把后台登录页当作公开可试玩 Demo。

## 很可能被问到

1. 为什么每个 Agent 不单独持有钱包？解释自己的管理场景，不把个人取舍说成其他方式不可能。
2. 服务端被攻破会怎样？说明热钱包和权限隔离，不能只说“私钥加密了”。
3. MoneyKey 泄露会怎样？解释限额、域名约束与撤销；Key 本身仍然是凭据。
4. 审批可以绕过硬额度吗？当前不能；批准后仍要通过额度检查。
5. 能买什么？给出真实已验证的 x402 服务案例与对应文章，不把协议支持说成任意 API 都能付款。
6. 新手不懂测试币能不能用？如实说明当前门槛，并听反馈。
7. 为什么一个钱包、多条链？同一地址各链余额独立，无自动换币或跨链。
