## 演示前（提前 30 分钟，按顺序）

```bash
# 0. 一次性：给 MoneySwitch 钱包打 2 测试 USDC（由你本人运行）
node tools/m6/fund-vault.mjs --to 0xFEd3f24cee2B3E2d94ad9f561ead4fEA589Ce2e3 --amount 2 --yes

# 1. 起测试网栈（已在跑就跳过；密码在 .data/testnet/.pw）
DEMO_SELLER_PAY_TO=0x28D99765A108279Ca8A92cc6543B6104cEeb33BE MONEYSWITCH_WALLET_PASSWORD="$(cat .data/testnet/.pw)" pnpm demo:testnet

# 2. 钱包解锁（服务重启后需要；或在 Dashboard 的 Wallet 页输入 .pw 里的密码）

# 3. 把 Money MCP 装进 Claude Code（Key 在 .data/testnet/demo-key.txt）
claude mcp add moneyswitch -e MONEY_API_BASE=http://127.0.0.1:4020 -e MONEY_API_KEY=<demo-key.txt 的内容> -- node C:/1mineyswitch/apps/mcp/dist/index.js
```
