# README product screenshots

These unchanged 1280 × 720 PNGs are from the MoneySwitch v0.7.6 technical
demo recorded on October 9, 2026, using an isolated instance on Monad testnet.
They show test tokens with no monetary value. Two scripted HTTP clients
exercise the payment API; the recording does not portray live LLM reasoning.

| File | Screen |
| --- | --- |
| `dashboard-keys.png` | Separate keys for direct-payment and approval flows. |
| `dashboard-approval.png` | A pending 0.01 test USDC payment awaiting a human decision. |
| `dashboard-bills.png` | Two settled payments totaling 0.02 test USDC, with transaction links. |

Key prefixes are masked by the Dashboard. These images contain no full
MoneyKey, administrator token, wallet private key, recovery phrase or
confirmation code. Do not publish the recording instance's data directory.

[Watch the recording](https://moneyswitch.dev/videos/technical-demo/).
The existing cover illustrations and video posters are reused from
`site/assets/`; video binaries remain in the
[media release](https://github.com/dongsheng123132/moneyswitch/releases/tag/metropolis-videos-2026-10-09)
and are not added to Git history.
