# MoneySwitch · 深圳 DemoDay · 5 分钟讲稿

2026-10-11。8 页，约 4 分钟讲述 + 1 分钟现场演示。先打开演示文稿、已登录的 Key / 账单页面及 Solana 交易页，排成连续标签页。投屏只展示不含 Key、令牌、助记词及私人用途的数据。

## 第 1 页 · 一句话价值 · 00:00–00:25

**核心句：一把 MoneyKey，花钱可控、账单可查。**

大家好，我今天带来的是 MoneySwitch。AI 已经能替我们写代码、查资料、执行任务；下一步，它也会遇到需要付费的服务。我们想解决一个很具体的问题：怎么让 AI 能花钱，同时让出钱的人掌握额度和审批，并且看懂每一笔账。

## 第 2 页 · 痛点 · 00:25–00:55

**核心句：给 AI 一个付款能力，还需要给人一个控制入口。**

假设我有三个 Agent：一个查数据，一个写代码，一个处理内容。让它们共用钱包，很难区分谁花了什么钱；直接把私钥交给 AI，又把签名能力暴露出去了。出了问题，我需要知道，这笔钱由哪个 Key 发起，付给哪个服务，是否已经付款，还剩多少预算。这些应该一眼能看清。

## 第 3 页 · 三步工作原理 · 00:55–01:30

**核心句：人发 Key，AI 请求服务，MoneySwitch 按规则付款。**

第一步，人给每个 Agent 发一把 MoneyKey，配置额度和可访问的服务。第二步，AI 用这把 Key 调用 MoneySwitch 的 HTTP 接口，请求付费资源。第三步，遇到兼容的 x402 服务时，MoneySwitch 检查报价和规则，再完成签名、付款和记账。AI 拿的是调用凭据；钱包签名密钥留在部署者自己的服务器上。

## 第 4 页 · 人的控制 · 01:30–02:05

**核心句：小额按规则走，需要人决定的时候就停下来。**

我们支持每天、累计和每次请求的额度，也支持允许域名和人工审批线。到了审批线，AI 会把审批链接交给人，等待决定；人批准后，硬额度限制仍然有效。测试网 Key 和主网 Key 分开，测试时不会跨到真实资金。请求还可以指定公链，卖家不支持这条链就拒绝，不会悄悄换链。

## 第 5 页 · 人看得懂的 Key 和账单 · 02:05–02:35

**核心句：让预算和付款结果变成可审核的界面。**

每个 Key 是一张预算卡片，可以搜索、筛选，并直接打开对应账单。账单把真实资金和测试币分开汇总，待核对金额单独提醒。金额、Key、时间和状态优先展示，展开后再看请求、收款方和链上交易。用途可以选填、默认隐藏；它是 Agent 的自述备注，方便核对，也避免要求大家交出完整任务内容。

## 第 6 页 · 已跑通的链上证据 · 02:35–03:15

**核心句：Base 和 Solana 的测试付款已经实际完成。**

今天我们在 Base Sepolia 和 Solana Devnet，各完成了一笔 0.01 测试 USDC 付款。Solana 这一笔还经过独立链上查询，确认最终完成。这里强调是测试币，没有真实货币价值；Solana 主网付款目前没有启用。这两笔记录能从账单直接打开交易浏览器，大家可以核对网络、金额和付款结果。

## 第 7 页 · 现场展示入口 · 03:15–03:45

**核心句：接下来用一分钟，从 Agent 的预算看到一笔已确认付款。**

这次展示的重点是人的使用体验：我先找到一个 Agent 的 Key，看它的额度占用；再进入账单，找到已付款记录，展开网络、收款方和交易链接，最后到独立交易浏览器核验。现场展示已经确认的付款，不需要重新发起一笔交易。

## 现场兜底与常见问题

**网站打开慢 / 登录失效。** 5 秒内切回文稿里的演示卡片，说明：“这是模拟数据，用来展示界面；链上付款证据是这两条测试网交易。”继续讲清“预算 → 账单 → 交易”的流程，不现场排查登录。

**交易浏览器打不开。** 使用第 6 页的已确认付款证据和链接，说明：“现场网络慢，链接可以会后独立核验。”不把加载失败说成付款失败，不重新付款。

**有人问旧 Solana ‘不确定’。** 说：“不确定表示目前的证据不足以确认是否扣款，我们保留记录和额度，不贸然重复付款。后来成功的 0.01 测试 USDC 是另一笔请求，有独立链上确认，不会拿它覆盖旧记录。”

**有人问备注是不是已验证的 Agent 任务。** 说：“不是，备注是调用方自述。账单可以核对 Key、请求、网络、收款方和交易；备注帮助理解用途，不证明任务真实性。”

**有人问员工隐私。** 说：“备注可不填，页面默认隐藏，也不强制采集完整提示词。管理员仍能读取已保存记录；当前的隐藏是展示选择，不是员工与管理员之间的权限隔离。”

**有人问 Solana 主网。** 说：“今天验证的是 Devnet。Solana 主网付款目前没有启用，主网能力不在今天的已完成演示里。”

**被压缩到 3 分钟。** 第 2–4 页各用核心句带过，第 5 页讲 20 秒，第 6 页讲 20 秒；现场只展示已付款账单和 Solana 交易，30 秒后回第 8 页。
