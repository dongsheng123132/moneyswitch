链路是这样的：Agent 用 MoneyKey 调用付费接口，卖方返回 HTTP 402 报价。

关键在第三步——在任何签名发生之前，MoneySwitch 的策略引擎先查额度、白名单和审批。

通过后本地签 USDC 授权，facilitator 在 Monad 上结算，内容返回，用量加一分钱。私钥从头到尾不离开 MoneySwitch。

底层全是现成的：x402 官方 SDK、Monad、Circle USDC。我们不发币，也不造协议。

护栏一共六道：单笔上限、日和总预算、服务白名单、人工审批阈值、一键撤销、防 SSRF 和重定向劫持。

所有检查都在签名之前完成，预算在并发下原子预留，不会超支。

所以就算网页里的 Prompt Injection 让它转 500 美元，单笔上限只有 0.2 美元——签名根本不会发生。
