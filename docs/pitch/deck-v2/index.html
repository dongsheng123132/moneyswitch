用户只需要分清三样东西：私钥是保险柜钥匙，永不显示，谁都不给；MoneyKey 是给员工的限额副卡，保密，只给自己的 AI；收款地址是收款码，公开，给任何人。

两样是秘密，一样拿来分享——把它们搞混，是唯一会让你丢钱的错误。

所以产品里专门做了防呆：如果有人把 MoneyKey 当收款地址粘进收费站向导，会被当场拦下、清空，不保存也不发送。
